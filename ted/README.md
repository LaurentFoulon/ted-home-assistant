# TED Energy Controller

HEMS multi-marques pour Home Assistant : TED pilote ensemble tous vos onduleurs
et batteries solaires, quelle que soit leur marque, comme une seule batterie. Il
lit votre compteur, calcule une consigne unique et la répartit entre tous les
appareils pour consommer votre propre production (zéro injection, heures creuses).

- Toute marque présente dans Home Assistant : Zendure testé et validé ; Anker
  SOLIX, Marstek, Deye, Huawei, Victron, SMA… via leur intégration
- Interface dans la barre latérale de Home Assistant
- Connexion à Home Assistant automatique (aucun jeton à créer)
- Application Android et accès à distance

*Multi-brand HEMS for Home Assistant: controls all your solar inverters and
batteries, whatever their brand, as one battery. Interface in French.*
