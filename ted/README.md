# TED Energy Controller

Pilotage solaire pour Home Assistant : TED règle la charge et la décharge de
vos batteries à partir de la mesure de votre compteur, pour consommer votre
propre production.

- Interface dans la barre latérale de Home Assistant
- Connexion à Home Assistant automatique (aucun jeton à créer)
- Application Android et accès à distance

Site : <https://ted-energy.fr>
